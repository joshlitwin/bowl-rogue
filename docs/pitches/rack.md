# Pitch: Stacked Spots (the rack never resets)

## 1. The idea
Each of the five spots holds a stack of pins you own; when a pin falls, the next pin in that stack rises for the next ball, and when a stack is empty the spot stays bare for the rest of the game. Points come from pins that fall, the multiplier comes from pins left standing, so every ball is a choice about which pins to spend and which to keep.

## 2. The turn
A game is nine balls at one persistent board. Stacks start 3 deep (15 pins), so strikes alone run you dry after three balls. Before each throw you weigh points now against the multiplier you keep, what rises underneath, and how many pins and balls are left. The drawn line outlines the pins it will hit; the timing needle only decides whether you get that outcome or drift one pin wide.

**Worked example, ball 5.** Standing: headpin spot has a Ripening pin at 14; left 3 is a Fuse pin; right 3 is an Anchor pin; left corner is a Lone pin; right corner is plain.
- Strike: 21 points x2 = 42, and five pins gone, Anchor included.
- Hit the Fuse only: it knocks the Ripening and Lone pins at double, (28 + 4 + 3) x2 for the standing Anchor = 70.
- Pick the Lone pin alone: 10 x2 = 20, but the Ripening pin grows to 17 and the same Fuse shot next ball pays 82. That is 102 over two balls against 70 plus whatever the fresh pins give, and it rests on the hardest shot on the lane.

## 3. Example pieces
Multiplier = 1 + bonuses from pins still standing after the ball. A strike is a flat x2.
1. **Plain pin**: spot value (5/3/2).
2. **Anchor pin**: while standing, +1 multiplier. Worth 0 when it falls.
3. **Ripening pin**: +3 points each ball it stays up; pays the total when it falls.
4. **Fuse pin**: when it falls it knocks both neighbours; pins it knocks score double.
5. **Lone pin**: if it is the only pin that falls, scores x5.
6. **Last-standing pin**: if it is the only pin left standing after a ball, +4 multiplier on that ball.
7. **Strike pin**: +3 multiplier on a strike; scores 0 if it falls any other way.
8. **Deep pin**: +2 points per pin still beneath it in its stack.
9. **Bare-spot pin**: while standing, +1 multiplier per empty spot on the board.
10. **Spring pin**: worth 1; returns to the bottom of its stack when it falls and never wears.
11. **Brittle gold pin**: pays $4 when it falls, then is destroyed.
12. **Dead wood** (added by the hall): worth 0; while standing, -1 multiplier (minimum x1).

Fuse fights Anchor and Lone as neighbours; Deep wants full stacks, Bare-spot wants empty ones; Strike pin wants the clears everything else punishes.

## 4. Escalation and forced change
- **Wear.** Every pin breaks after falling four times (notches on the pin). Four or five break per game, so each shop you buy several cheap pins and re-order stacks.
- **Depth.** Stack limit rises 3, 4, 5 across the run: more pins, longer sequences to plan.
- **The hall.** From game 3 it slides one Dead wood into a stack each game and posts a house rule, shown one shop ahead (strikes pay x1; corner spots refill a ball late; standing bonuses halved).

## 5. Strikes
On a plain rack a strike is still best. But it spends five pins from a finite supply and leaves nothing standing to multiply, so a built board usually pays more for a chosen partial. Strike and Spring pins make a strike build possible; it is one build, not the default.

## 6. Riskiest assumption and test
That the light throw lets players hit the subset they chose often enough that choosing matters, without one subset becoming the new identical ball. Test: one screen, nine balls, the example board with pre-built stacks, no shop. Log outlined pins against pins that fell, and which subset was picked. Pass: outcome matches the outline on 70% of throws and no subset is chosen more than four times in nine. Otherwise kill it.

## 7. Cut
Frames and the reset on a clear. Nine balls, one board.
